# botframe

botframe is an open-source design tool for the desktop. The browser draws the document as DOM elements.

**Try it in the browser: https://aleqsio.github.io/botframe/**

The website does not export files. For export and for the agent tools, use the desktop app.

## Start

```sh
bun install
bun run dev
```

On the first launch, botframe opens the welcome document. To open it again, use **File > Open Welcome Project**.
