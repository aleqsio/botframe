# Layout panel proposal

This folder holds the design handoff for the layout section of the properties panel.

- `prototype.html` is the interactive prototype. Open it in a browser. Card 16, "PROPOSAL", is the design to build. The other cards are the options that led to it.
- `01` to `06` are screenshots of card 16 in its main states.

The GitHub issue "Implement the layout panel proposal" gives the specification.
